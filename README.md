# Disaster Tweets Classification

Binary text classification of tweets as real disaster or non-disaster.

This project compares:

- Classical NLP using TF-IDF and machine learning
- Transformer-based text classification

## Dataset

Kaggle - Natural Language Processing with Disaster Tweets

## Evaluation

Models are evaluated on a held-out validation set using:

- Accuracy
- Precision
- Recall
- F1 Score

A final model is also evaluated using the Kaggle public leaderboard.
