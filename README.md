# Disaster Tweets Classification

Binary NLP classification of tweets as real disaster or non-disaster.

This project compares two approaches:

- Classical NLP using TF-IDF and machine learning
- Transformer-based text classification

## Dataset

Kaggle - Natural Language Processing with Disaster Tweets

## Evaluation

Models are evaluated on the same held-out validation set using accuracy, precision, recall, and F1 score.
